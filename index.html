Dokumentasi Teknis & Arsitektur

1. Git & GitHub: Digunakan sebagai Version Control System (VCS) untuk melacak setiap perubahan baris kode, memfasilitasi manajemen branch, menangani merge conflict, dan mengelola Pull Request secara kolaboratif.

2. npm (Node Package Manager): Berperan sebagai manajer dependensi untuk menginstal dan mengelola library eksternal (seperti Vite dan Bootstrap) serta mengeksekusi skrip otomatisasi melalui file package.json.

3. TypeScript: Berfungsi sebagai superset dari JavaScript yang mendisiplinkan struktur data melalui static typing (termasuk primitive, array, interface, union, dan generics) guna meminimalisir error saat runtime.

4. Vite & Environment Variables: Vite dipilih sebagai build tool modern untuk kompilasi lokal yang instan. Environment variables (file .env) diimplementasikan untuk memisahkan konfigurasi aplikasi rahasia dari source code utama demi keamanan data.

5. Peran Compiler, Transpiler, dan Bundler: TypeScript bertindak sebagai Transpiler/Compiler yang menerjemahkan kode TS yang ketat menjadi Vanilla JavaScript agar dapat dibaca oleh browser. Sementara itu, Vite bertindak sebagai Bundler yang bertugas memaketkan dan mengoptimalkan seluruh aset (HTML, CSS, JS) menjadi satu direktori dist/ yang ringan untuk diunggah ke server produksi (Netlify).
